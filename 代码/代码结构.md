# 代码结构说明

> 面向复核者：**哪个文件干什么、谁调用谁、按什么顺序跑**。
> 文件都放在 `代码/` 一层（不分子目录），因为论文附录按 `../代码/xxx.py`
> 直接嵌入全部程序清单，移动文件会让附录与脚本的相对路径一起失效。
> 逻辑上的分层见下表，每一层只依赖它下面的层。

---

## 二、逐文件说明

### 1. 求解层（唯一实现物理模型的地方）

| 文件 | 行数 | 职责 |
| --- | --- | --- |
| `solve_p1.py` | ≈400 | 问题一：物性取常数、$D=D(C)$，热方程与水分方程解耦；节点中心有限体积 + 后向 Euler + 追赶法；自带守恒检验与表 1/表 2 导出 |
| `solve_p234.py` | ≈460 | 问题二/三/四共用内核：物性随 $C$、$T$ 变化，两个方程 Picard 迭代耦合；问题四用贴体坐标 $\xi=r/R(t)$，$R(t)$ 由附件 2 的 PCHIP 插值给出 |

两个求解器的**函数骨架一一对应**，便于交叉验证：
`diffusion_coefficient` / `cell_weights` / `load_air_conditions` / `thomas` /
`_assemble` / `step_*` / `solve` / `main`。

### 2. 驱动与结果生成层

| 文件 | 职责 |
| --- | --- |
| `run_all.py` | 依次求解问题二/三（同一套物性）与问题四，把贴体坐标解插值到题面要求的固定物理位置，导出 `输出/result{23,4}_data.npz` |
| `prepare_outputs.py` | 按题面要求的时间间隔（result2 每 1 s、result3/4 每 60 s）整理成一维二进制 `输出/result{2,3,4}.bin` + `result_meta.json`；问题四超出当前半径的位置留空 |
| `xlsx_style.py` | 四张结果表的统一表头与样式（对应附件 3 模板），只依赖 openpyxl |
| `build_result1.py` | 由 `result1_data.json` 写 `result1.xlsx`（温度、水分浓度两张表） |
| `build_results234.py` | 由 `result3/4.bin` 写 `result3.xlsx`、`result4.xlsx`（末列"药材表面"） |
| `build_result2_xlsx.py` | 流式写 `result2.xlsx`（约 910 万格，峰值内存与行数无关），保存后补写工作表 XML 得到列宽与冻结窗格 |
| `paper_tables.py` | 由四个结果表生成正文表 3–表 6 的 Markdown |

### 3. 对照、灵敏度与自检层

| 文件 | 职责 | 参考结论 |
| --- | --- | --- |
| `p23_variants.py` | 网格 $N=20/50/100/200/400$ × 时间步 $\Delta t=2\sim120$ s × 两种口径，共 20 组对照 | 一阶收敛；口径差 +6.3% 与网格无关 |
| `closure_rhod.py` | 第三种口径（干基密度守恒）的独立实现，并与前两种交叉验证 | 48.39 h（N=100），与体积密度口径相差 −15.6% |
| `sens.py` | $h$、$h_m$、$D$ 各 ±20% 的烘干时长灵敏度 | $D$ 主控（48.9–70.0 h） |
| `shrink_criterion.py` | 斜率截距比 $r=b/a$ 判据、阈值表、几何与 $b$ 扫描 | 判据与门槛表 |
| `verify_paper_numbers.py` | 把论文里每个可核验数字重算一遍（365 项），输出 `输出/数据自检报告.json` | 不一致 0 项 |
| `export_baseline_tables.py` | 从论文 `.tex` 导出表 1–表 6 的基准值 JSON（无论文时供上面那个脚本比对） | — |

### 4. 插图层

| 文件 | 职责 |
| --- | --- |
| `prepare_figure_data.py` | 生成绘图所需的全部派生数据到 `输出/figdata/`（附件序列、问题一细网格解、问题四不收缩对照解、灵敏度、阈值扫描、物性曲线） |
| `make_figures.py` | 40 张图（原理示意图 + 数据图），出图后自动做缺字/裁切/刻度重叠自检，并导出矢量 PDF、300 dpi PNG 与灰度预览 |
| `figlib/figstyle.py` | 统一样式（配色、字号、轴线、网格），取自开源仓库 mathmodel-kit（Apache-2.0） |
| `figlib/export_figure.py`、`figlib/visual_qa.py` | 出图自检闭环（scipilot-figure-skill，MIT），随包分发见 `figlib/NOTICE.md` |

### 5. 交付与工具层

| 文件 | 职责 |
| --- | --- |
| `check_env.py` | 解释器、四个依赖、中文字体自检（缺字体时直接报错，避免图里出现方框） |
| `make_delivery_pdf.py` | 把论文 PDF 等比缩放到 A4 且四边页边距 ≥2.5 cm，并打印页数、页面尺寸与实测页边距 |

## 三、运行顺序

完整顺序就是 `reproduce.sh` 的内容（`--fast` 只跑前两步）：

```
1  solve_p1.py  →  build_result1.py                        问题一（约 10 s）
2  run_all.py   →  prepare_outputs.py  →  build_results234.py
                →  build_result2_xlsx.py  →  paper_tables.py   问题二/三/四（约 7 min）
3  p23_variants.py --table / closure_rhod.py --all / sens.py /
   shrink_criterion.py                                     对照与灵敏度（约 43 min）
4  prepare_figure_data.py                                 插图数据（约 12 min）
5  make_figures.py                                        全部插图（约 1.5 min）
6  verify_paper_numbers.py --json                         数据自检（约 1.5 min）
```

论文侧：`论文全文.tex` 用 XeLaTeX/Tectonic 编译 → `论文全文.pdf`（未缩放）
→ `代码/make_delivery_pdf.py` → `论文全文_交付版.pdf`（提交用）。

## 四、改代码时的自检顺序

1. **守恒检验**：跑 `solve_p1.py`，相对残差应在 $10^{-14}$ 量级；
2. **交叉验证**：把 `solve_p234.py` 的物性换成附录 2 常数物性，应与问题一
   逐点一致（实测 2.6×10⁻¹² °C）；
3. **网格收敛**：`p23_variants.py --n-list 20,50,100,200`，增量应逐次减半；
4. **数据一致**：`verify_paper_numbers.py`，365 项必须全部一致；
5. 前四步都过，再去看结果数值与图。
